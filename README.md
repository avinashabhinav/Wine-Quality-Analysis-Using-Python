# 🍷 Wine Quality Analysis Using Python
This project provides an exploratory data analysis (EDA) of the Red Wine Quality dataset. Using Python’s powerful data science libraries, the analysis uncovers key factors that influence wine quality and visualizes relationships between physicochemical properties and quality ratings.

# 📂 Repository Structure
* WineQT.csv → Dataset (Red Wine Quality)
* Insights_into_Wine_Quality_through_Exploratory_Data_Analysis.ipynb → Main analysis notebook
* Numpy.ipynb → Supporting notebook for numerical operations
* README.md → Project documentation
  
# ⚙️ Technologies Used
* Python
* NumPy → Numerical computations
* Pandas → Data manipulation
* Matplotlib & Seaborn → Visualization
# 📊 Key Insights
Correlation between alcohol content and wine quality

Influence of acidity, sulphates, and chlorides on taste

Distribution of wine quality scores

Feature importance for predicting wine quality

# 🚀 How to Run
Clone the repository:

bash
git clone https://github.com/avinashabhinav/Wine-Quality-Analysis-Using-Python.git
Navigate to the project folder:

bash
cd Wine-Quality-Analysis-Using-Python
Install dependencies:

bash
pip install -r requirements.txt
Open the Jupyter Notebook:

bash
jupyter notebook Insights_into_Wine_Quality_through_Exploratory_Data_Analysis.ipynb
